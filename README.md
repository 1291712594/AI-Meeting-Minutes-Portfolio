# AI会议纪要智能体

**产品经理**：朱东刚 · [zdg1291712594@163.com](mailto:zdg1291712594@163.com)

**项目状态**：✅ PRD定稿于2025.09，MVP开发与测试于2025.11完成

## ✨ 一句话简介

自动将会议录音转化为结构化纪要，并强制输出可执行任务清单（含责任人+截止时间）的AI智能助手，解决会议纪要混乱、待办遗漏、效率低下的核心痛点。

## 👤 我的角色

作为本项目唯一产品经理，我从0到1完成：

- 用户调研与需求定义（访谈3名互联网从业者轻量沟通，提炼核心痛点）
- 产品设计与功能优先级规划（输出PRD、原型、用户旅程图）
- 技术选型与落地验证（Dify+LangChain架构设计、用户测试与迭代）

## 🎯 核心价值

- **省时**：纪要整理时间从平均47分钟压缩至8分钟（测试者反馈）
- **闭环**：强制输出“责任人+截止时间”，解决待办遗漏痛点
- **差异化**：区别于单纯转写工具，聚焦“任务落地”全流程

## 🌟 项目亮点

- **从真实痛点出发**：从灵感来自建筑行业跨部门会议的“会后责任不清”亲身经历
- **数据驱动**：3轮自测迭代，行动项提取准确率达85%左右
- **技术落地力**：4周完成MVP，用Dify+LangChain实现多智能体协同

## 🛠️ 技术栈

- 应用框架：Dify（快速搭建原型）
- 智能体框架：LangChain（转写、摘要、任务提取多智能体分工）
- 语音识别：阿里云百炼API
- 大模型：DeepSeek（高性价比，适配MVP）
- 设计工具：Figma、pixso、ProcessOn
