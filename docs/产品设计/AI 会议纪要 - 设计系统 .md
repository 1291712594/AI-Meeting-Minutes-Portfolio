# AI 会议纪要 - 设计系统

## 1. 颜色规范

- 主色 (Primary): #2563EB (按钮、选中态)
- 背景 (Page): #F8FAFC (页面底)
- 卡片 (Card): #FFFFFF (内容区)
- 文字 (Main): #1E293B (标题)
- 文字 (Secondary): #64748B (辅助说明)
- 警示 (Alert): #EF4444 (缺失标红、错误)

## 2. 字体规范

- 数字/英文：Inter / San Francisco
- 中文：系统默认无衬线 (PingFang SC)
- 标题：18px Bold
- 正文：14px Regular
- 辅助：12px Regular

## 3. 组件规范

- 按钮高度：44px (最小点击区域)
- 卡片圆角：12px
- 输入框边框：1px #E2E8F0
